# clean-comments

Normalize every comment in the repository to a strict style.

## Hard rules

1. **Language**: English only. Translate any Portuguese or other-language comment into concise English. Do not keep bilingual duplicates.
2. **Length**: One line maximum. Collapse multi-line explanations. If the thought needs more than a line, delete the comment and let the code (or the commit message / PR description) carry the context.
3. **Minimalism**: Default to *no comment*. Keep a comment only when the *why* is non-obvious: a hidden constraint, an invariant, a workaround for a specific bug, or behavior that would surprise a reader. Remove every comment that merely restates what the next line of code already says.
4. **No AI/assistant references**: Strip any mention of Claude, Anthropic, GPT, Copilot, ChatGPT, "pair-programmed with…", "generated by…", TODO tags that name an assistant, etc.
5. **No sensitive or environment-leaking data**: Remove local absolute paths (`/home/<user>/...`), usernames, personal email addresses, machine hostnames, modification dates, edit timestamps, "last updated on …" headers, and author bylines inside source files (authorship belongs in git history and LICENSE/README, not in comments).
6. **No dead code in comments**: If code is commented out, delete it. If it's load-bearing documentation, promote it to the README or a design note.
7. **No decorative banners**: Drop ASCII art, section separators like `//========`, "Section: X" headers. Use real code structure instead.

## Scope

Apply to every text source file in the repo:

- TypeScript / JavaScript: `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, `.cjs`
- Styles: `.css`, `.scss`, `.sass`, `.less`
- HTML / templates: `.html`, `.htm`
- Config: `.json` (jsonc-style trailing `// …`), `.yaml`, `.yml`, `.toml`
- Shell / scripts: `.sh`, `.bash`, `.zsh`
- Python: `.py` (both `#` comments and docstrings that are purely redundant)
- Markdown: do not touch body prose; only fix HTML-comment blocks `<!-- … -->` that leak the same categories of data.

Explicitly **skip**:

- `node_modules/`, `dist/`, `.git/`, `build/`, `public/models/` (binary GLBs).
- License headers at the top of third-party files.
- JSDoc / TSDoc doc comments on exported APIs **if** they add non-obvious contract information. Trim them to one line when possible; delete them when they only restate the signature.

## Allowed one-line comment shapes

- `// why we clamp: downstream expects non-negative` (why, not what)
- `// workaround for maplibre #1234: terrain needs tile=256`
- `// keep in sync with regions.ts order`
- `// Mozilla: Firefox < 115 lacks AbortSignal.any`
- `// FIXME: tighten when ground-truth polygons land`

## Forbidden comment shapes

- `// increment counter` (states the obvious)
- `// TODO(claude): refactor` (AI reference, wrong author tag)
- `// Last modified 2026-11-13 by narayane` (sensitive, redundant with git blame)
- `// /home/narayane/.../src/foo.ts` (local path leak)
- `// ---------- MAP LAYER CONFIG ----------` (decorative)
- `// This function returns the active region. It takes no arguments. It is used by the sidebar.` (multi-fact, redundant, too long)
- `// Generated with assistance from an AI pair programmer` (AI reference)

## Procedure

When invoked:

1. **Sweep**. `rg -n '^\\s*(//|#|<!--)' --type-add 'web:*.{ts,tsx,js,jsx,css,scss,html,sh}' -tweb` (or equivalent) to list every single-line comment candidate.
2. **Multi-line sweep**. `rg -n '/\\*' -tweb` and `rg -n '"""|\\'\\'\\'' -t py` to list block comments and docstrings.
3. **Classify each hit** against the rules above:
   - *delete* (fails minimalism or leaks data)
   - *rewrite* (translate / shorten / de-leak)
   - *keep* (passes all rules)
4. **Apply edits** using the editor's exact-match edit tool. Preserve indentation. Never introduce a new blank line where none was needed.
5. **Verify**. Re-run the sweep; confirm zero occurrences of the forbidden patterns:
   - `(?i)\\bclaude\\b|\\banthropic\\b|\\bcopilot\\b|\\bchatgpt\\b` in comments
   - `/home/|/Users/|C:\\\\Users` in comments
   - `@author\\b|Modified:\\s|Last [Uu]pdated` in comments
   - Non-ASCII Latin letters (`[áàâãéêíóôõúçÁÀÂÃÉÊÍÓÔÕÚÇ]`) inside `//` or `/* */` comments
6. **Type-check** the project (`tsc -b` or equivalent) to confirm no accidental code deletion.

## Report format

After applying, print a short summary:

```
clean-comments: 42 files scanned, 17 comments deleted, 9 rewritten, 0 forbidden patterns remain.
```

Then list any comments that were kept and required judgment, so a reviewer can double-check.
